# PARALLAX AI 0.1.0-alpha.3

**Windows x64 prerelease · 19 November 2026 · Unsigned**

[Download assets](https://github.com/Sahiru2007/parallax-ai/releases/tag/v0.1.0-alpha.3) · [Getting started](../../README.md#quick-start) · [Changelog](../../CHANGELOG.md)

## What's included

The first published GitHub prerelease brings the existing coding workspace, Compare and Replay, provider settings, and Windows packaging together with the runner repairs verified after local alpha.2.

- **Coding:** isolated worktrees, repository instructions and tools, streamed activity, per-command approvals, follow-ups, file diffs, explicit export/apply, and completed evidence.
- **Comparison:** independent A/B conversations, tool receipts, worktrees, and patches from one captured baseline. Both candidates remain available for review, including sequential generation and interrupted turns.
- **Replay:** a five-step scenario editor, fixed request fixtures, explicit response gates, real Chromium/DOM checkpoints and frames, aligned version switching, stale-evidence detection, and standalone Playwright regression exports.
- **Providers:** Gemini, OpenAI, and loopback Ollama; exact selected IDs; runner-side Windows Credential Manager keys; separate connection and harmless tool checks; configurable rounds and available usage.
- **Context:** bounded file/search/log observations, paged/ranged tools, complete redacted command downloads, request-size diagnostics without source text, and retained provider-native tool context.
- **Recovery:** candidate-owned checkpoints and completed tool receipts, inspection of uncertain operations, bounded Windows persistence retries, and visible/cancellable temporary HTTP 429/503 handling. At most two automatic retries and 60 seconds of retry waiting/request time per explicit continuation; no automatic extra model-round allowance.
- **Windows:** Tauri 2/WebView2, per-user NSIS, bundled production assets, offline fonts, native folder selection, a private runner on an available port, process ownership, and retained per-user sessions/evidence.

The README is rebuilt around these workflows with actual screenshots, architecture, setup, safety boundaries, and an honest account of model/evaluation limits. There is no UI redesign or new live model task in this release.

## Installation and data

Run the installer and open **PARALLAX AI** from Start. No development servers or checkout are needed. Configure a provider through **Manage providers**, or start the labeled no-key demo.

Normal data lives under `%LOCALAPPDATA%\dev.parallax-ai.desktop`. Default uninstall retains sessions and Windows Credential Manager entries. The optional app-data deletion setting is destructive; removing a cloud key through settings deletes that credential separately. Browser-development and desktop profiles are separate.

## Known limits

- This is an **unsigned experimental alpha**, verified on a development Windows PC, not a clean VM. Download reputation/SmartScreen and clean-machine provisioning are not established by local tests.
- Real provider results depend on model capability and quota. Controlled providers exercise plumbing and tools, not live inference. No new paid API calls were made for this release.
- After a forced native crash, the app can restore an older selected session. The interrupted session remains visible and correctly marked; explicitly reopen it from the rail or **Reopen session** selector. The initial automatic-selection failure is retained even though the subsequent full rerun passed; manual reopening was verified separately.
- The retained Express-1 live diagnostic continuation reached 18/18 rounds without an edit or passing regression. It is not counted as a successful fix or a new benchmark sample.
- Replay supports local Chromium HTTP fetch/XHR within the documented scenario format; it is not a general browser recording system.
- Worktrees are not an OS sandbox. Approved commands run project code as your user. Review commands and use trusted repositories.
- Large repositories and patches may exceed current limits. Automatic merges, automatic apply, and automatic everyday-worktree cleanup are not implemented.

For reproducible bugs, [open an issue](https://github.com/Sahiru2007/parallax-ai/issues/new) with the exact version/model, steps, and redacted logs.
